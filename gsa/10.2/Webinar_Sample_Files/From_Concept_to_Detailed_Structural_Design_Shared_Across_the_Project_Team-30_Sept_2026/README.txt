From Concept to Detailed Structural Design Shared Across the Project Team

This folder contains a Grasshopper sample file that demonstrates the workflow presented in the webinar.

Requirements

- Oasys GSA 10.2
- Rhino 8
- GSA_GH plugin
- Autodesk Revit 2026
- Rhino.Inside.Revit plug-in


Workflow

1. Open Revit and load the Family Library Template.rte template file.
2. Ensure that the template contains the required Revit families and family mappings.
3. From the Rhino.Inside menu in Revit, launch Rhino and Grasshopper by selecting Start > Rhino > Grasshopper. (This option is available only if the Rhino.Inside.Revit plug-in is installed.)
4. Open the GSA-to-Revit Model Export.gh Grasshopper sample file.
5. On the Grasshopper canvas, locate the GSA Open Model component.
6. Use the GSA Open Model component to open the Multi-Storey Core Wall Building with Dome Structure.gwb GSA model.
7. Once the model has been opened successfully, allow the Grasshopper to complete the export workflow.
8. Verify that the model has been exported successfully to Revit and is displayed in the active Revit project.
